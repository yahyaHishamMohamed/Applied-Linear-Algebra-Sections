# Applied Linear Algebra - Section Implementations 📐🤖

Welcome to the official repository for the coding implementations covered in the **Applied Linear Algebra** sections. This repository bridges abstract linear algebra theory with hands-on machine learning and artificial intelligence applications.

---

### 📂 Repository Contents

* **`Perceptron.ipynb`**: Implementation of the foundational linear classifier (Perceptron algorithm), demonstrating how vector dot products and weights separate classes linearly.
* **`Kmeans.ipynb`**: Implementation of the K-Means clustering algorithm, showcasing distance metrics and vector space partitioning in action.

---

### 🎯 Purpose & Scope
The goal of these implementations is to help engineering students and learners visualize how core mathematical concepts—such as vectors, matrices, and geometric transformations—form the backbone of modern AI, computer vision, and embedded systems workloads.
